# Ideology

*The ten political positions on three axes, and the language every other system speaks.*

## What this covers

Ideology is the political position a person, government or movement occupies, distinct from a political party and from a [[Movements|movement]] itself. The current design calls for ten political positions on three axes, which provide a common political language for systems elsewhere in the game. The running game still uses an older implementation of six ideologies on two axes, so pages describing current behaviour must keep that implementation difference visible rather than treating the two models as the same thing.
