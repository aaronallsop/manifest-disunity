## 1. The key

**Two kinds of task.**
- **You start it.** You open a session with `/go <name>` and the studio does the work. You may be asked
  things along the way.
- **You do it.** The work is yours: a conversation (with Pluto, say), getting your thoughts out, playing a
  build, making a decision. Some of these need a session. Others are one answer on the board.

**Each task has:** a `/go` name (lowercase, unique, and it keeps that name for life) · a plain title · its
kind · who (roles as the road names them) · **waits for** (other task names, or "nothing") · **done when**
(one plain sentence) · **size** (sessions for a "you start it" task, your time for a "you do it" task,
always labelled) · where it must run, but only where that matters.

**How tasks become free.** A task is **free** when everything it waits for is done. That is when its card
appears, whatever its milestone number. Only one session runs at a time (one live session, D263), so two
free tasks are never worked on together. When several are free, they are listed in the road's order.

**Four rules for the list itself:**
1. **Every milestone ends with a close-out task.** It checks that the milestone is really done, looks at
   what changed, and plans the next milestone in detail.
2. **A task that overruns keeps its name.** Its card says "part 2" and carries on. It gets a new name only
   when the work turns out to be a different job. *(Proposed, not in the road. The first trace in section 7
   shows why it is needed.)*
3. **A conditional task** (marked ◇) appears only if what triggers it happens.
4. **Hiring is not a task.** When a task's role has no file yet, Saturn writes the file at the start of
   that task (D262).

**Size codes** (explained in section 6): **[m]** measured comparable · **[a]** like past one-session jobs ·
**[b]** no comparable in this project, a guess · **[c]** the road itself names this as uncertain · **[d]** the
fault's own record says the fix is small.
