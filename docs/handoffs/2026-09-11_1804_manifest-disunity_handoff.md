## 7. What was learned this session

**Advice inside an artefact cannot protect that artefact.** The fix after the first stale handoff was
a warning written inside the handoff. A session only reads that warning *after* it has decided to
trust the file carrying it. Measure the thing instead: git already knows which commit wrote the
document, so the staleness is computable and now is computed. Rule 10 in `PROGRAMMER-RULES.md`.

**Check where a fact actually lives before repeating it.** Finding A says the Farmers Union "has
never been given a verb". Checking `data/parties.json` showed **no movement has a verb there at
all** — verbs live in the Movement Register, which is design-stage. The finding is still right; the
reason is different, and it would have gone to Aaron's board in the wrong words.

**The board's own staleness has a colour.** The livery comment says yellow means *the page is warning
you about its own trustworthiness*. A board that was two days behind is exactly that, so the headline
is `warn` rather than `bad`.
